# CATIA Code Mode / PTC 全方位对照评测

日期：2026年11月10日。结论：PTC的代码编排与结果压缩能力已验证，但本轮真实自主建模比已有批处理宏接口更慢、首个脚本提交通过率更低。不能据此宣称“切换PTC即全面提升效率”。反馈链路能帮助模型纠正已知失败，但还不能保证任意修改自动恢复。

## 1. 测试设计与适用范围

采用同一`gpt-6.1-sol`、high推理强度、独立新会话、同一CATIA与底层MCP。主对照为原生宏接口直接调用，对比由模型写JavaScript、经QuickJS-WASM及Python broker驱动相同接口。直接模式原本就能在一个宏内完成多步，不能人为拆成大量调用来制造PTC优势。主对照双方均为3个模型侧工具；现有零件修改跟进才使用104直接工具对比PTC三个入口。

主对照每复杂度/模式仅1例、顺序执行；工具连接和schema装载先完成，再计用户指令至最终答复。耗时包含推理、工具、诊断、轮询、截图及最终说明；不含首次应用启动。另做18次只读传输对照（1/6/18调用，各3重复，交替次序、共享已连接后端）。两类测试回答的问题不同，不混合排名。模型与接口已有明确宏契约提示，这不是无提示能力测试。

现有应用仍为0.7.0、WebUI仍使用OpenCode；本次更新的是独立CodeMode0.2.0及其Skill/后台错误分类，未替换WebUI智能体后端。

## 2. 效率：收益与新增开销

### 2.1 受控只读传输

|相同目录查询次数|直接 / PTC中位耗时（ms）|直接 / PTC返回envelope字节|返回体积减少|
|---|---:|---:|---:|
|1|3.42 / 229.76|5,660 / 2,014|64.4%|
|6|16.72 / 307.81|33,960 / 2,018|94.1%|
|18|45.74 / 584.36|101,880 / 2,050|98.0%|

这里统计完整序列化结果envelope（含text/structuredContent重复），PTC含启动答复和最终状态答复，不是仅统计最终return的极小值。共享连接建立约3.39秒，不计两臂计时；PTC每次Guest执行开销仍计入。代码输入每段约221–222字节，schema装载不计入该传输指标。每次底层查询仍实际执行，PTC节省的是返回模型的数据，不减少CATIA工作量。这些字节不是token或账单。

可见优势是：三个入口、代码循环/分支/筛选、完整中间结果留本地、精炼return、可审计程序。代价是：编排和参数层出错、启动成本、目录/轮询放大、截图负载、诊断链加长。CATIA仍串行执行；程序跨调用不具备原子性，需`catia_plan_run`持有完整多步跨度。

## 3. 不同复杂度的执行准确性

|级别|原始要求要点|直接首个提交|PTC首个提交|最终独立几何核查|
|---|---|---|---|---|
|L1|D36×6圆盘，1特征/1草图|通过|通过|两者通过|
|L2|90×60×8板、4个D8通孔，圆心(±30,±18)|通过|预筛查拒绝；新ID修正后通过|两者通过，4孔位置/半径/抽样贯通正确|
|L3|120×90底板10→12、R18凸台顶Z18、8个D6外孔+中心D12|通过|预筛查拒绝；新ID修正后通过|两者通过，9孔位置/半径/抽样贯通正确|

直接首个脚本通过3/3，PTC首个脚本通过1/3、修正后3/3。两次拒绝均在CAD写入前，不能说成生成了错误几何。实际最终模型均保存/重开，L3最终体积130,957.168026mm³；宏代码保留原底板对象，再将其厚度改为12，并非替换新零件。

评估方另从CATIA导出STEP，经OCP独立内核检查实体有效性、单实体、理论体积、边界尺寸及指定圆孔圆柱边界的中心/半径/数量。每孔16个周边材料点与9条轴向穿透线抽样核查贯通。8个最终新建/修正样例（6主对照+F1/F2）全部满足本次几何目标；没有孔的圆盘孔检查为空集。此检查针对选定Z轴圆孔，不是任意孔洞、曲面、每个点或制造要求的完全证明。

### 已有零件原位修改 M1：未通过

PTC面对“加厚一些”先询问目标厚度，副本文件哈希不变。随后明确要求将底板8→10mm、保持四个D8孔位置与贯通：模型原位将BasePad改到10mm，但原切除深度仍为8mm。实际体积52,391.5046mm³，四孔贯通应为51,989.3807mm³，多出402.1239mm³，等于4个孔各残留2mm底层的体积。独立STEP检查确认4个孔均未贯通。模型识别并报告了失败，未把错误结果称为通过，亦未自动恢复原始状态。

原因包含关联特征未随动，以及“仅改底板”与“保持通孔”对当前定深特征存在冲突。正确流程应先检查孔的限制类型，说明是否需要把孔改为贯穿/随动深度，再执行或澄清。只改一个参数不等于满足整个修改指令。

保存相同副本时触发SaveAs覆盖模态框；前端回合结束导致原RPC返回丢失。评估方处理确切测试文件的覆盖提示后，依据同路径Saved=true、落盘时间/哈希和原生尺寸作本地人工开发对账；原始中断记录保留，标记FAILED，不伪造RPC成功、不重放。此处有外部协助，不能计作全自动成功。

直接修改跟进的副本与已打开副本具有相同CATIA内部标识，CATIA拒绝同时加载；上游工具却返回Opened字符串。模型核对实际完整路径后停止，未修改错误文档。该臂是测试布置失败，不计修改成功率、也不与PTC做有效耗时比较。保留全部错误及弹窗记录。

## 4. 歧义复杂指令

清洁测试在真实已建L3件仍可访问时进行：A4“把孔扩大一倍”；A5“外圈孔重新均布一圈，边距留10”。两模式均未执行几何写入，样例落盘哈希前后一致。直接臂仅有原生三工具，不能读取已有几何；PTC可发现内层几何工具。因此这里只比较语义澄清，不据此宣称PTC几何理解优于直接104工具。

|测试|观察耗时|表现|
|---|---:|---|
|A4 direct|15.14秒|先询问，未发生几何写入|
|A4 ptc|55.56秒|先询问，未发生几何写入|
|A5 direct|25.41秒|先询问，未发生几何写入|
|A5 ptc|54.38秒|先询问，未发生几何写入|

A4两者最终均询问“所有9孔还是仅外圈孔、是否按直径翻倍”，未擅自执行。PTC通过实际读取给出Φ6→Φ12、Φ12→Φ24的待确认方案。其过程消息曾先说按直径2倍处理，最终才询问，措辞仍易给人已决定的印象；应先陈述待确认条件。

A5两者均询问孔中心或孔边到哪条边缘；PTC额外提到凸台外缘和均布圆心。仍未充分指出矩形板外缘上的“处处等边距10”与同一圆周均布一般不能同时满足，需要进一步定义最小边距/选定边和分布圆半径。PTC解决编排，不自动解决设计语义或约束矛盾。M1也表明：澄清一个尺寸后，仍可能遗漏特征关联冲突。

早期A1–A3是在CATIA不可用/执行门阻断期间的探索，未计入以上清洁结果；全部历史保留。初期连接与宏契约失败也未混入有效建模队列。

## 5. 错误自反馈与修正

F1故意将目标D40×8圆盘做成4mm，实际体积5,026.548246mm³，目标10,053.096491mm³，少50%。插件返回FAILED/KNOWN_FINISHED，保存失败候选。`ptc_status(include_feedback=true)`实际返回本次候选截图作为MCP ImageContent及厚度/体积偏差，校验图片文件、SHA256及字节绑定，非仅返回图片路径。

真实模型先看截图和量测，明确“截图不能精确判断厚度”，保持8mm目标及原体积不变，以NEW request生成修正候选并保存重开成功；81.77秒、7个模型侧MCP调用。独立STEP也通过。说明截图+数值可支持至少这类已知尺寸错误的自主修正；不是全部错误修复率100%。

F2验证具体错误透传：拒绝含全局视图访问的原宏，无CAD写入、无候选截图，返回“CATIA全局对象仅允许 Documents.Add；后续请用局部doc”。给模型原被拒宏及单程序/长轮询建议后，一次新宏修正成功，74.05秒，独立几何检查通过。这是修复后、给出额外材料的跟进，不与原L3的238.36秒组成受控速度提升结论。

新增能力：绑定的成功/失败原生截图可回送视觉模型；提取实际特征深度、实体/草图数和体积偏差；保留最多1200字符上游具体错误；记录启动/后端/总耗时；`wait_ms=0..20000`异步等待减少模型短轮询。另修复严格已知的“未连接到CATIA前失败”和“只读无活动文档”被误判为未知写入的情况；RPC/超时等未知状态不因此放行。

限制：代码不会自行理解图片或自行调用模型，当前闭环由自主模型主动读反馈并决定新请求。绑定截图覆盖原生执行器候选，不是所有catia-v5修改错误的统一自动截图钩子。没有回滚事务；错误状态下已有几何可能保留。普通截图不能验证精确尺寸、背面孔底或A级连续性，必须辅以参数、体积与几何检查。未知结束仍阻断，禁止自动重放/解锁。

## 6. 验证和后续优先级

31项CodeMode/真实QuickJS/安装/反馈测试、90项核心回归（含4项实际上游适配契约）通过；Python/JavaScript及Skill格式检查通过。保持完整失败证据，不覆盖历史成绩。新增的是开发扩展0.2.0，不是0.7.0整套应用的全新正式发布。

下一步先缩减重复目录发现、在一段程序内组织依赖操作、只返回必要数值、按需而非每次回送截图，并复测多次重复和随机顺序。之后完善原位修改的依赖分析、贯通/最小壁厚断言、实际活动文档绑定和同文件Save语义，再扩展多视图/截面反馈与有限修正次数。现有样本不足以给出泛化准确率、可靠成本排名或统计显著提升。

本轮不包含GLM对照、H20部署、自由曲面/A级曲面G1/G2验收、全部104工具、生产件或复杂装配体验证。程序SUCCEEDED仍不等于工程验收；`geometry_verified=false`不被强行改写。
