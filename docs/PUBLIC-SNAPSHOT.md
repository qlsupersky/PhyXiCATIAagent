# 公开快照整理

本仓库以已安装 0.6.5 为基线。2026-10-30 发布整理仅作用于独立的公开源码目录，未改变本机安装或历史证据。

- 移除运行缓存、凭据、客户文件、会话和机器相关验证记录。
- 将示例服务器地址改为 loopback，将文档路径改为用户占位符。
- Git 不追踪可重建桥接器或大型 OpenCode 运行时；新增固定版本 SHA-256 下载脚本。安装包包含原版固定运行时。
- 安装程序在源码缺少运行时时自动调用下载脚本；卸载文件清单补充图文页模块。
- 历史测试使用临时目录；移除需要私有客户文档的可选测试片段。
- 公开仓库包含完整主插件源码、宏桥接源码、示例和测试。第二套 MCP 上游部署独立管理。
